# Points system update (tiers, cumulative, Igolflex)

## Tiers
Updated per product (inclusive ranges) via seed.

## Cumulative
Within one invoice, quantities of the same product are summed across distributors; tier points are awarded once on that total (shown on the first line of that product).

## Igolflex
After each line quantity confirm: Yes/No popup → optional seaux count → bonus 20–41:1, 42–81:2, 82+:3. Stored per line; server recomputes.
